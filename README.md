# Foundation of Java Development – Lab Sheet 7

## Multithreading in Java

This repository contains 15 Java programs based on Multithreading, covering basic and advanced concepts with practical examples.

### Topics Covered
- Thread Class
- Runnable Interface
- Thread Name and Priority
- Thread Scheduling
- isAlive() and join()
- Sleep Method
- Synchronization
- Race Condition
- Synchronized Block
- Producer-Consumer Problem
- wait() and notify()
- Deadlock Prevention

### Programs
- **Q1–Q9:** Basic and Intermediate Multithreading
- **Q10–Q12:** Race Condition and Synchronization
- **Q13:** Producer-Consumer Problem
- **Q14–Q15:** Deadlock and Deadlock Prevention

### Requirements
- Java JDK 19 or higher
- VS Code / Eclipse / IntelliJ IDEA

### Objective
To understand multithreading in Java, thread synchronization, communication between threads, and deadlock handling through practical programs.
